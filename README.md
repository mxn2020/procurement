# Procurement / Purchase Order System

## Pages & Features

### 1. Dashboard
- Open POs count & total value
- Pending approvals queue
- Spend by category chart
- Supplier performance overview

### 2. Purchase Requisitions
- Create new requisition with line items
- Requisition approval workflow (submit → review → approve/reject)
- Requisition history with status filters
- Attach supporting documents

### 3. Purchase Orders
- Generate PO from approved requisitions
- PO detail: vendor, items, quantities, pricing, delivery date
- PO status tracking (draft → issued → partially received → closed)
- Print / email PO to supplier
- Amendment & cancellation handling

### 4. Goods Receipt
- Record received goods against PO
- Partial receipt support
- Quality inspection checklist
- Discrepancy reporting (quantity / damage)

### 5. Suppliers / Vendors
- Vendor registry with contact & banking info
- Vendor qualification & rating system
- Contract management per vendor
- Vendor performance analytics

### 6. Catalogs & Items
- Internal item catalog with categories
- Preferred supplier per item
- Price comparison across vendors
- Item specification sheets

### 7. Invoices & Payments
- Match invoices against POs & receipts (3-way match)
- Invoice approval workflow
- Payment status tracking
- Aging analysis

### 8. Reports
- Spend analysis by category, vendor, department
- PO cycle time reports
- Savings & budget variance
- Export as PDF / CSV

### 9. Settings
- Approval hierarchy configuration
- Budget limits & thresholds
- Notification rules
- User roles & permissions
